# IPL-Analysis-Dashboard-2008-2019
Developed an interactive multi-page Power BI dashboard analyzing IPL data from 2008–2019.
Designed KPI cards to track matches, teams, runs, fours, and sixes.
Built analytical visualizations for top teams, batsmen, bowlers, boundary hitters, toss outcomes, and match results.
Implemented venue-based geographic analysis using Power BI Maps.
Generated actionable insights from 756 IPL matches across multiple seasons.
